## Référentiels

Statuts : `BACKLOG` · `READY` · `TODO` · `IN_PROGRESS` · `BLOCKED` · `REVIEW` · `QA` · `DONE` · `CANCELLED`

Types : Epic · Story · Task · Bug · Refactoring · Security · Documentation · DevOps · Architecture · UI/UX · Test · Spike

Priorités : P0 bloquant/sécurité · P1 avant livraison · P2 amélioration · P3 confort

## Lecture des dérives

| Signal | Piste |
|---|---|
| Temps passé > estimation sans blocage | Estimation, profil ou autonomie à revoir |
| Beaucoup de BLOCKED | Dépendances ou cadrage |
| REVIEW qui dure | Disponibilité du lead, qualité |
| Réouvertures fréquentes | Tests ou DoD insuffisants |
| Beaucoup d'IN_PROGRESS | WIP trop élevé |
